## 프로젝트 개요

JCodeQuest는 사용자가 프로그래밍 문제를 풀고 자신의 활동과 순위를 확인할 수 있는 코딩 문제 풀이 플랫폼입니다.

프론트엔드, 백엔드, 코드 채점 서버로 구성된 웹 서비스를 팀원들과 협업하여 개발했습니다.

## 담당 기능

프로젝트에서 `feat/ranking-page` 브랜치를 사용하여 다음 기능을 개발했습니다.

- **Ranking:** 사용자 순위 정보를 보여주는 페이지
- **MyPage:** 사용자의 개인 활동 정보를 확인하는 페이지
- **UserProfile:** 사용자 프로필 정보를 표시하는 페이지

## 개발 환경

- **프론트엔드:** 웹 UI 개발
- **백엔드:** API 서버 연동
- **데이터베이스 및 인증:** Supabase
- **실행 환경:** Docker Compose
- **버전 관리:** Git 및 GitHub

프로젝트 실행 환경은 프론트엔드 `5173`, 백엔드 `8000`, 채점 서버 `8002` 포트를 사용했습니다.

## 문제 해결 경험

### Supabase 설정 문제

개발 과정에서 Supabase 관련 설정 문제를 경험했습니다.

환경 설정을 점검하고 서비스 간 연결 상태를 확인하며 문제를 해결했습니다.

### 여러 서비스의 실행 환경 관리

프론트엔드, 백엔드, 채점 서버 등이 연결되어 있어 개별 프로그램만 실행하는 것보다 환경 구성이 복잡했습니다.

Docker Compose를 활용하여 프로젝트의 컨테이너를 함께 실행하고 서비스 연결 상태를 확인했습니다.

## 배운 점

이 프로젝트를 통해 팀 단위 Git 브랜치 작업, 웹 페이지 구현, API 및 데이터 연동, Docker 기반 개발 환경 관리 경험을 쌓았습니다.

특히 개별 페이지 구현뿐 아니라 다른 서비스와의 연결을 확인하고 문제를 해결하는 과정의 중요성을 배웠습니다.
