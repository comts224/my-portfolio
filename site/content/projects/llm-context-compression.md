## 프로젝트 개요

대규모 언어 모델(LLM)이 긴 문서를 처리할 때 발생하는 토큰 사용량 문제를 줄이기 위해, 질문과 관련된 핵심 정보를 선별하는 방법을 연구했습니다.

단순히 입력 문맥을 줄이는 것이 아니라, 질문에 필요한 정보를 최대한 유지하면서 답변 정확도와 토큰 효율성을 함께 고려하는 것을 목표로 했습니다.

## 진행 기간 및 활동

- **진행 기간:** 2026년 여름 ~ 2026년 10월
- **논문 제출일:** 2026년 10월 12일
- **주요 활동:** 문맥 압축 방법 비교, 실험 환경 구성, 데이터셋 기반 성능 평가, 실험 결과 분석

연구 초기에는 LLM이 긴 문맥을 처리하는 방식과 기존의 정보 검색 방법을 살펴보았습니다. 이후 실험 환경을 구성하고 여러 문맥 처리 방법을 비교하면서 성능을 분석했습니다.

실험 결과를 정리하고 연구 내용을 논문으로 작성하여 2026년 10월 12일에 제출했습니다.

## 프로젝트 목표

- 긴 문맥에서 질문에 필요한 핵심 정보 선별
- LLM 입력 토큰 수 감소
- 답변 정확도와 토큰 효율성 비교
- 문맥 압축 방법의 장점과 한계 분석

## 사용 기술 및 환경

- **프로그래밍 언어:** Python
- **운영체제:** Ubuntu 24.04
- **모델 실행 환경:** Ollama
- **언어 모델:** Gemma 및 Qwen 계열 모델
- **평가 데이터셋:** LongBench, HotpotQA
- **평가 항목:** 답변 정확도(F1), 근거 정보 보존 정도, 입력 토큰 수

## 진행 내용

### 1. 실험 환경 구성

Ubuntu 환경에서 Ollama를 활용하여 LLM을 실행하고, Python으로 실험을 수행할 수 있는 환경을 구성했습니다.

### 2. 문맥 처리 방법 비교

질문에 필요한 정보를 효율적으로 제공하기 위해 다음 세 가지 방식을 비교했습니다.

- **Truncate:** 입력 문맥을 일정 길이로 잘라 사용하는 방식
- **BM25:** 질문과 관련성이 높은 문서를 검색하는 방식
- **Compress:** 질문에 필요한 정보를 선별하여 문맥을 압축하는 방식

### 3. 성능 평가 및 결과 분석

LongBench와 HotpotQA 데이터셋을 활용하여 각 방식의 답변 정확도와 입력 토큰 사용량을 비교했습니다.

특히 답변 정확도뿐 아니라 질문에 필요한 근거 정보가 얼마나 유지되는지도 함께 살펴보았습니다.

이를 통해 문맥 압축이 토큰 사용량을 줄이는 데 얼마나 효과적인지, 그리고 답변 품질에는 어떤 영향을 미치는지 분석했습니다.

## 실험 결과

문맥 압축 방식은 기존 문맥을 그대로 사용하는 방식이나 BM25 검색 방식보다 입력 토큰 수를 크게 줄일 수 있었습니다.

일부 실험에서는 문맥 압축 방식이 약 100개 수준의 입력 토큰만 사용하여, 다른 방식보다 훨씬 적은 문맥으로 답변을 생성했습니다.

다만 답변 정확도는 BM25 방식보다 낮게 나타나는 경우도 있었습니다. 이를 통해 문맥을 짧게 만드는 것만으로는 충분하지 않으며, 질문에 필요한 정보를 정확하게 선별하는 과정이 중요하다는 점을 확인했습니다.

결과적으로 문맥 압축의 토큰 효율성은 확인했지만, 답변 정확도를 안정적으로 유지하기 위해서는 추가적인 개선이 필요하다는 결론을 얻었습니다.

## 배운 점

이번 연구를 통해 LLM의 성능을 평가할 때 답변 정확도뿐만 아니라 토큰 사용량과 정보 보존 정도도 함께 고려해야 한다는 점을 배웠습니다.

또한 실험 환경을 구성하고 여러 방법의 결과를 비교하면서 데이터 처리, 성능 평가 및 결과 분석에 대한 경험을 쌓을 수 있었습니다.

특히 예상한 결과와 실제 측정 결과가 다를 수 있다는 점을 경험하면서, 객관적인 실험 결과를 바탕으로 방법의 장점과 한계를 판단하는 것이 중요하다는 사실을 알게 되었습니다.

## 향후 개선 계획

앞으로는 질문과 관련된 문장을 더욱 정확하게 선별할 수 있도록 문맥 압축 방법을 개선하고자 합니다.

또한 다양한 질문 유형과 데이터셋에서 실험을 진행하여 문맥 압축의 효과가 달라지는 원인을 분석할 계획입니다.

궁극적으로는 답변 정확도를 최대한 유지하면서 입력 토큰 사용량을 줄일 수 있는 효율적인 문맥 처리 방법을 연구하는 것이 목표입니다.
