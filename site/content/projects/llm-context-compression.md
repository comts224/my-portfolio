## 프로젝트 개요



대규모 언어 모델(LLM)이 긴 문서를 처리할 때 발생하는 토큰 사용량 문제를 줄이기 위해, 질문과 관련된 핵심 정보를 선별하는 방법을 실험했습니다.



## 프로젝트 목표



- 긴 문맥에서 질문에 필요한 정보 선별

- 입력 토큰 수 감소

- 답변 정확도와 토큰 효율성 비교



## 사용 기술 및 환경



- Python

- Ubuntu 24.04

- Ollama

- Gemma 및 Qwen 계열 언어 모델



## 진행 내용



LongBench와 HotpotQA 데이터셋을 활용하여 여러 문맥 처리 방법을 비교했습니다.



기존 문맥을 그대로 사용하는 방식, BM25 검색 방식, 문맥 압축 방식을 실험하고 답변 정확도와 토큰 사용량을 측정했습니다.



## 실험 결과



문맥 압축 방식은 입력 토큰 수를 크게 줄이는 데 효과적이었습니다. 다만 답변 정확도가 모든 경우에서 가장 높지는 않았으며, 정보 선택 방법을 개선할 필요가 있음을 확인했습니다.



## 배운 점



LLM의 성능을 평가할 때는 답변 정확도뿐만 아니라 필요한 연산 자원과 토큰 사용량도 함께 고려해야 한다는 점을 배웠습니다.



또한 실험 결과를 비교하고 분석하는 과정에서 데이터 처리와 모델 평가에 대한 이해를 높일 수 있었습니다.
